# Aura Perfumes – Fragrance Discovery & E-commerce UI/UX
Aura Perfumes is a perfume e-commerce website UI/UX concept designed to help users discover fragrances based on their mood, occasion, and personal preferences. It offers a curated browsing experience for male, female, and unisex perfumes, with detailed fragrance notes for every product.

## Key Features
- Explore perfumes based on mood
- Discover fragrances for different occasions
- Browse male, female, and unisex perfume collections
- View detailed perfume information
- Explore top, middle, and base notes for each fragrance
- Discover fragrances based on scent profiles
- Enjoy an elegant and user-friendly shopping experience

## Fragrance Details
Each perfume includes its fragrance composition:
- **Top Notes:** The first scents noticed after applying the perfume
- **Middle Notes:** The heart of the fragrance
- **Base Notes:** The deeper scents that last longer
